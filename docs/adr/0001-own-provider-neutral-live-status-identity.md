# Own provider-neutral Live Status identity

Via assigns stable typed IDs to network entities and keeps government identifiers in a versioned alias registry because TDX and city feeds can change independently of the real transport network. Routing pins an immutable Network Snapshot and consumes only normalized Arrival Estimates, Service Conditions, Bike Availability, and feed health; provider schemas remain inside adapters. This adds an identity registry and snapshot boundary, but prevents provider migrations, identifier churn, and raw status semantics from forcing changes through routing and native clients.
